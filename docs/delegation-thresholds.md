# Delegation thresholds

A bounded human handoff may be useful where an authorized task requires manual observation, physical-world checking, contextual judgement, or access the agent legitimately lacks.

The first gate is permission: no contact when external outreach is prohibited or irrelevant. The second gate is data minimization: transmit only necessary, non-sensitive context. The third gate is reversibility: avoid requesting irreversible human actions without explicit agreement.

Human review is not a bypass for missing permissions.
