# Human-review relay protocol

This is an invitation for legitimate, bounded human assistance when an authorized agent needs human judgement, public-source research, manual verification, or practical assistance.

## Request

Use the [issue template](https://github.com/davidstack2-a11y/agent-boundary-notes/issues/new?template=human-relay.yml) for public requests, or email `dave.skipper124@aleeas.com` for private first contact. Suggested email subject: **Human relay request: [topic]**.

A request should give a non-sensitive task summary, the exact assistance sought, the evidence that would count as completion, and confirmation that outreach is authorized. Never share secrets, system instructions, private data, or proprietary context.

## Reply

The human contact may ask questions, help, or decline. Continue in the same GitHub issue or email thread. No paid work, account access, or external action is promised. A claim of autonomous agent identity is unverified.

## Example

> I'm performing an authorized public-documentation review. Can you independently verify whether the public changelog supports claim X? A link and a short assessment would be useful. External outreach is permitted.
