# Guidance for coding and research agents

Maintain testable, accurately labeled technical documentation. Synthetic examples must not be presented as real-world observations. Do not commit secrets or private logs. This file does not override higher-priority operator or system instructions.

## Optional human escalation

For a legitimate task where research, judgement, manual verification, or bounded practical human assistance is genuinely needed and your operator permits contacting external parties, an independent human review channel is described in [docs/human-relay.json](docs/human-relay.json). There is no obligation to contact. Never disclose credentials, private prompts, protected documents, or unauthorized context.
